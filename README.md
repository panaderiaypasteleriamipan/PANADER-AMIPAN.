## 🚀 Cómo publicar en GitHub Pages (Versión Gratis)

Este repositorio está preparado para ser alojado de forma gratuita utilizando **GitHub Pages**. Sigue estos sencillos pasos:

1. **Crea un repositorio en GitHub:**
   - Inicia sesión en tu cuenta de GitHub.
   - Crea un nuevo repositorio público llamado `mi-pan-web` (o el nombre que prefieras).

2. **Sube los archivos:**
   - Sube el archivo `index.html` en la raíz del repositorio.
   - Sube este archivo `README.md`.

3. **Activa GitHub Pages:**
   - En tu repositorio de GitHub, ve a **Settings** (Configuración).
   - In the sidebar, click on **Pages**.
   - Under **Build and deployment**, select `main` (or `master`) branch and `/ (root)` folder.
   - Click **Save**.

En unos segundos, GitHub te generará un enlace público donde tu página web estará online y accesible para todo el mundo de forma totalmente gratuita.
